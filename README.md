TinyRTOS is an educational real-time operating system (RTOS) developed from scratch for the STM32H533RE Nucleo board based on the ARM Cortex-M33 processor. The objective of the project is to gain a deep understanding of operating system internals by implementing the fundamental mechanisms that enable multitasking, resource management, and memory protection on embedded systems.

Unlike using an existing RTOS such as FreeRTOS or Zephyr, TinyRTOS focuses on designing and implementing each kernel component manually.
